## ReRxBot
一个使用OneBot11机器人协议，然后后端是Python的一个QQ机器人

## 如何使用
首先，clone源代码

`git clone https://github.com/ExMC-Github/ReRxbot.git`

然后切换到那个目录

`cd ReRxbot`

然后修改某些东西，看看config.py，改点配置

`nano config.py` or `notepad config.py`

然后使用`pip3 install -r requirements.txt`安装依赖后基本上就可以启动了，报错了什么的我不知道，没测试过，我自己是在Re-NEPython环境运行的，那个没开源
