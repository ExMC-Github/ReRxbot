This directory contains DLLs that must be installed before Python can run.

If using Windows 3.1, then copy the 2 files in the win31 directory 
to your Windows system directory.

If using Windows 95 or NT, copy the 2 files in the nt95 directory to your
system directory.  On win95, this is called "SYSTEM", on NT, this is called
"SYSTEM32"

Please see the main readme (..\readme.txt) for full details.
